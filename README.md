# Jamshedpur October 2026 Planner

A small offline-friendly HTML/CSS/JS project for planning October weekends in Jamshedpur.

## Run
Just open `index.html` in Chrome/Safari/Edge.

No build step and no server required.

## Features
- Select each October weekend/day.
- Step-by-step itinerary starting from Dimna.
- Walking segments and approximate pacing.
- "Open in Maps" buttons using Google Maps links.
- Check off completed steps.
- Progress is saved in browser localStorage.
- Alcohol-free plans.
- Budget target shown per day.
- Mobile-friendly layout.

## Notes
- Walking distances are intentionally approximate. Use the Maps button and choose a safe pedestrian route.
- Do not force a 5 km walk if your body is not comfortable with it.
- Event details can change; check the event page before leaving.
